    Images

    Off by default, so this page never contacts the internet. Put image file names in the CSV (e.g. wedding.jpg) and add the files with “Add images…”.

    CSV column guide
    trackWhich timeline the row belongs to (e.g. Family, Pop Culture). Each track gets its own band.
    titleRequired. The event's name.
    startRequired. 1972, 1972-06, 1972-06-12, 6/12/1972, June 1972, 1920s, c. 1905
    endOptional. If present, the row becomes a bar covering that span.
    descriptionText for the pop-up. Blank lines make paragraphs.
    imageImage file name you add alongside the CSV.
    colorOptional per-event color, e.g. #3b82f6.

    Column names are flexible (date, category, start_date… also work). Comma, tab, semicolon and pipe (|) files are all fine.

    Exports with no header row in the order Title | Start Date | End Date | Description are recognised automatically; you'll be asked which track they belong on.

    Everything stays in this browser tab. Nothing is uploaded or stored, and closing the window clears it all. Use File → Save project to keep your work.

      Tilt looks down onto the timeline, Turn swings it so time runs off toward the horizon, and Depth sets how far it stretches. Zoom moves the camera in or out, and Focus aims it higher or lower — slide it up to zoom in on the top track. “Facing you” stands the writing upright so it never stretches. The background shows wherever the timeline doesn't reach. Each stop can use its own camera.

      Vignette

      Vignette settings
      Color

      Shades the edges of the frame to draw the eye to the middle. Amount sets how dark, Size how much of the centre stays clear, Softness how gradual the fade is, and Roundness whether it follows the frame's shape or makes a circle. Captions and event cards sit above it.

      Stops

      Make your own slideshow: zoom and pan to a view, then press + Stop (or S). Open an event and choose “+ Stop here” to feature it. Your stops last until you close the page.

      Each stop saves a view: where the camera is, how far in it's zoomed and which tracks are in view. Click the pencil on a stop to set how the camera travels there, how long it holds, a caption, and an event card to feature. Drag the handle to reorder.

      The video is drawn frame by frame, so it can take longer than real time but never drops frames. Keep this tab in front while it works. The frame shape is set in the Stops tab.

      Publish a web page

      Saves one self-contained .html file with your data, photos, tracks, look and stops built in. Viewers can zoom, scroll, open events, show or hide tracks and play the slideshow, but nothing can be edited. It needs no server or internet connection, so you can put it on your web site, email it, or open it straight from a folder.

      Project

      A project file keeps everything together: the data, photos, tracks, look, stops and export settings. Nothing is kept in the browser, so save a project before you close the window. You can also drop a project file onto the page to open it.
