📊 Timeline Publisher

Create beautiful, interactive storytelling timelines and animated slideshows from your own data.

📈

Interactive Timelines

Import data from CSV, visualize events on an interactive timeline with pan and zoom controls. Organize events into color-coded tracks.

🎬

Animated Slideshows

Create "stops" to guide viewers through your story. Configure timing and transitions. Present in full-screen mode with keyboard controls.

🎨

3D Visualization

Toggle 3D view with adjustable camera controls: tilt, turn, zoom, focus, and depth. WebGL rendering with canvas fallback.

🌙

Vignette Effect

Add professional edge darkening to presentations and exports. Customize intensity, coverage, softness, shape, and color.

💾

Export & Publish

Export as PNG images, MP4 videos, CSV data, or standalone HTML pages for web sharing. All processing happens locally—no server required.

🖥️

Desktop App

Native macOS app with menu bar, keyboard shortcuts, file dialogs, and Dock integration. Also works as a web app in any browser.
